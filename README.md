# ProjectMegan - A Music Album Browser

A professional music catalog browsing application built using Angular and TypeScript.

## 🚀 Live Demo

🔗 View the live application : [(https://megantheestallionmusiclibrary.vercel.app/home)]

##✨ Features

###• Dynamic Catalog Showcase: Renders a clean home page featuring componentized cards for at least three distinct music albums out of the box.
###• Deep-Dive Detail Routing: Features interactive navigation that takes users to a dedicated details page mapping out full album properties, song tracklists, and explicit track durations.
###• Componentized Architecture: Adheres to a highly organized layout built on independent, reusable components to guarantee application maintainability.
###• Wildcard Error Redirection: Implements a robust routing guard configuration that captures invalid URLs and automatically forwards users to a dedicated error view.

##🛠️ Tech Stack & Tools

• Framework: Angular (v19+)
• Language: TypeScript
• Styling: CSS Layouts (Supports Tailwind CSS / Angular Material)
